# AI-анализатор рынка конкурентов

Персональный инструмент для мониторинга и анализа конкурентов в выбранной нише с использованием мультимодальности (анализ текста и изображений).

## Ниша
Графический дизайн и анимация (дизайн-студии, брендинговые агентства, 2D/3D анимационные студии)

## Конкуренты (для примера)
- https://www.behance.net/ (референсы и портфолио)
- https://dribbble.com/ (дизайн-конкуренты)
- https://motionographer.com/ (анимация)

## Структура
- data/ - скриншоты лендингов, PDF-отчеты конкурентов
- app/ - backend FastAPI
- ui/ - интерфейс

## Установка и запуск
```bash
pip install -r requirements.txt
cp .env.example .env  # добавить API-ключ
uvicorn app.main:app --reload
```

## Функционал
- Анализ текстового описания конкурента
- Анализ изображений лендингов/скриншотов
- Автоматический парсинг сайтов через Selenium
- Оценка визуального стиля (design_score) и потенциала анимации (animation_potential)
- Сборка в desktop-приложение через PyQt6 + PyInstaller
